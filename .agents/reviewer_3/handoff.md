## 2. Logic Chain

1. **Implementation Code Correctness**:
   - `AuthProvider.tsx`, `LoginPage.tsx`, and `RoleGuard.tsx` contain solid production code handling corrupted storage, username-to-email conversion, role redirection, and null role guard safety.

2. **Test Suite Failure Cause**:
   - `src/tests/auth.test.ts` was modified to execute async calls against `authService` and `teacherService`.
   - In environments where Supabase is configured (`VITE_SUPABASE_URL` present), `authService.validateInvitation` delegates to Supabase database queries.
   - Because `auth.test.ts` does not mock `isSupabaseConfigured()` or database queries, it fails with database errors (`invalid input syntax for type uuid: "grp-1"`) and mismatched error strings (`'كود الدعوة غير صحيح أو غير مفعّل.'` vs `'كود الدعوة غير صحيح.'`).
   - Consequently, running `npm run test` fails with exit code 1.
