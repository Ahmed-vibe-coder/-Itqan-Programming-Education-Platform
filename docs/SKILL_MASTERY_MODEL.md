# Skill Mastery Model & Concept Tracking — منصة "نواة كود" (nawa-code)

**تاريخ التوثيق**: 30 يوليو 2026

---

## 1. نموذج خريطة المهارات (Skill Taxonomy)

يتم تتبع المفاهيم البرمجية عبر 4 حالات تدريجية:
1. **غير متكون (not_started)**: لم يقرأ الدرس ولم يمارس التطبيق.
2. **قيد التعلم (learning)**: أتم قراءة الدرس وجارٍ حل التمارين التفاعلية (نسبة تمكن 1-75%).
3. **يحتاج مراجعة (needs_review)**: ظهر تعثر أو تكرار خطأ في بوابة الإتقان أو الامتحانات.
4. **أتقن المفهوم (mastered)**: اجتز بوابة الإتقان بنسبة 100% بدون استخدام تلميحات مباشرة.
