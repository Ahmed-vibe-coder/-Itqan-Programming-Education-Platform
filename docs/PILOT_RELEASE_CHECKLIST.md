## 1. قائمة التفقّد الفنية والتأكيد التشغيلي (Verification Checklist)

- [x] **حساب المعلم والمالك:** تسجيل الدخول وإدارة كافة الكورسات والأسئلة والطلاب من لوحة القيادة.
- [x] **الدعوات أحادية الاستخدام:** تفعيل وتخصيص الكود الذري `max_uses = 1` ومطابقة الاسم الثلاثي.
- [x] **تسجيل الدخول باسم المستخدم:** تحويل وتخزين المعرف دون كشف كلمة السر السيرفراتية.
- [x] **دروس المناهج المكتملة:** 36 درساً منشوراً في HTML و CSS و JS مفحوصة عبر `npm run content:validate`.
- [x] **بنك الأسئلة والـ 24 نوع:** محركات العرض والتصحيح الآلي الخادمي والتوافق مع شاشات اللمس (Tap & Up/Down).
- [x] **منشئ الامتحانات والتصحيح:** تثبيت لقطات الأسئلة غير القابلة بالتعديل والتصحيح السيرفراتي المحمي.
- [x] **الألعاب البرمجية والـ XP:** تشغيل ألعاب التدرّب وحفظ النقاط دون تكرار.
- [x] **إدارة الذكاء الاصطناعي والمساعدة المحدودة:** تفعيل الإشراف ومكتبة الشروحات المعتمدة وحظر الذكاء الاصطناعي أثناء الامتحانات الرسمية.
- [x] **نظام الشهادات المعتمدة:** إصدار تلقائي عند تحقيق نسبة %80 وتفعيل صفحة التحقق العامة `/verify/:code`.
- [x] **تطبيق PWA والجوال:** شريط التصفح السفلي وحفظ الدروس أوفلاين وسرعة الاستجابة على كافة الشاشات (320px–430px).
- [x] **الأمان والاختبارات الآلية:** تمرير جميع اختبارات Vitest الـ 23 بنسبة نجاح 100% والبناء الخالي من الأخطاء.
