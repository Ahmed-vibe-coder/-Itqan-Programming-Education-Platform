# Backup and Restore Guidance — دليل النسخ الاحتياطي واستعادة البيانات

**تاريخ التقرير:** 30 يوليو 2026

---

## 1. استراتيجية النسخ الاحتياطي التلقائي والدوري
1. **حزم المحتوى المرجعية (Content Packages Backup):**
   - الكورسات، الوحدات، والدروس منسخة ومحفوظة في مجلد `content-packages/` بصيغة JSON خاضعة لنظام ضبط النسخ Git.
   - تشغيل الأمر `npm run content:export` لتصدير أحدث التعديلات من قاعدة البيانات إلى ملفات JSON المرجعية.

2. **قاعدة البيانات سحابياً (Supabase Postgres Database Backup):**
   - دعم النسخ اليومي والشهري التلقائي لجداول الـ Postgres عبر لوحة تحكم Supabase.
   - استخدام `pg_dump` لتصدير جداول المحتوى وبنك الأسئلة والنتائج دون تصدير مفاتيح السرية أو كلمات المرور.

3. **إجراءات الاستعادة في حالات الطوارئ (Disaster Recovery):**
   - في حال تعثر أي جدول، يتم تشغيل سكربت البذر الآلي `npm run content:seed` لإعادة بناء هياكل الكورسات من حزم JSON المعتمدة.
