# Adaptive Spaced Review Model — منصة "نواة كود" (nawa-code)

**تاريخ التوثيق**: 30 يوليو 2026

---

## 1. محرك المراجعة المتباعدة وحظر النسيان

تُجدول المراجعات بناءً على فترات متباعدة (1 يوم -> 3 أيام -> 7 أيام -> 14 يوم -> 30 يوم) ومربوطة بتقييم الثقة الذاتي للطالب (متأكد، أعتقد أنها صحيحة، غير متأكد) لمنع النسيان وتثبيت المفاهيم.
