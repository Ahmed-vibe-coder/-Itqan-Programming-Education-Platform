## 1. هيكل المشاريع التراكمية ومعرض الأعمال (Projects & Portfolio)

تتضمن المشاريع مهام تطبيقية كاملة في HTML و CSS و JavaScript (مثل بناء صفحة شخصية، بطاقة تعريفية، لعبة تخمين الأرقام) وتمر بمراحل:
`not_started` -> `in_progress` -> `submitted` -> `approved` مع مراجعة وملاحظات المعلم وتوثيقها في معرض الأعمال الشخصي (Portfolio).
