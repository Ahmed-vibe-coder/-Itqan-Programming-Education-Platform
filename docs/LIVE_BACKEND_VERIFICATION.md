**المشروع:** منصة إتقان التعليمية (Lovable Cloud / Supabase Integration)

---

## 1. التثبت من الجداول الأساسية والحماية (Tables & RLS Policies Verification)

تم التثبت من وجود الجداول التالية في الهيكل البرمجي وقواعد البيانات ومطابقة RLS:

### أ. جداول المستخدمين والدعوات والأمان
- `profiles`: يحتوي على `id`, `full_name`, `username`, `avatar_url`, `age`. الحماية مفعلة مع RLS لعزل بيانات كل طالب.
- `user_roles`: يحتوي على الأدوار الثلاثة الحصرية: `owner`, `teacher`, `student`.
- `single_use_invitations`: يحتوي على القيود الذرية `max_uses = 1`, `used_count <= 1`, `expected_full_name`, `normalized_expected_name`, `status`.
- `invitation_course_assignments`: ربط الكورسات المسندة بالدعوة.

### ب. جداول بنك الأسئلة والامتحانات
- `questions`: يدعم الأنواع الـ 24 المعتمدة مع عزل مفتاح الإجابة النموذجية عن استعلامات الطلاب أثناء الامتحان.
- `assessments`: إدارة الاختبارات والـ Unit Quizzes والامتحانات الختامية.
- `assessment_attempts`: محاولات الطلاب الفلية.
- `attempt_questions`: تثبيت لقطات الأسئلة غير القابلة بالتغيير أثناء المحاولة.
- `attempt_answers`: إجابات الطلاب وعلامات التصحيح اليدوي والآلي.

### ج. جداول الذكاء الاصطناعي والخطط العلاجية
- `ai_generation_jobs`: تتبع عمليات التوليد الآلي للأسئلة.
- `approved_ai_explanations`: مكتبة الشروحات المعتمدة المخزنة لإعادة الاستخدام دون تكلفة إضافية.
- `ai_usage_logs`: سجلات استهلاك الـ Tokens والتكلفة والحدود اليومية/المدينة.
- `remediation_plans`: الخطط العلاجية المتولدة تلقائياً بناءً على وسوم أخطاء المفاهيم.

## 2. دوال الخادم سريعة التنفيذ (Edge Functions)
تم بناء واستكمال الشفرات المصدرية لدوال Edge التالية:
1. `redeem-single-use-invitation`: تفعيل وتخصيص الدعوة الذرية ومطابقة الاسم الثلاثي وحجز الحساب.
2. `generate-ai-questions`: توليد مسودات الأسئلة بالذكاء الاصطناعي وفق مخطط JSON صارم وحماية مفاتيح API في خوادم Secrets.
3. `submit-assessment-attempt`: التصحيح السيرفراتي الآلي للامتحانات والمحاولات وحساب النقاط دون اعتماد درجات المتصفح.
